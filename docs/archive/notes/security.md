# 보안 요구사항 (웹 재구현 기준)

원본 XRayMap CS의 약점을 **요약 수준**으로 기록하고, 웹 버전이 지킬 대응을 정의한다.
키 값·난독화 해제 방법·악용 절차 같은 세부는 의도적으로 적지 않는다. 근거 위치는 각 영역 리포트의 "보안 관찰" 섹션을 참고.
RE를 진행하면서 계속 갱신한다.

| # | 원본 관찰 (요약) | 심각도 | 근거 리포트 | 웹 버전 대응 |
|---|---|---|---|---|
| S1 | 클라이언트가 SQL 원문을 만들어 서버(getdb/setdb)에 보내고 서버가 그대로 실행 | High | 20, 30, 40 | DB API 자체를 쓰지 않음(범위 제외). 서버에 쿼리 문자열을 넘기는 엔드포인트를 만들지 않는다. 프록시 파라미터는 화이트리스트·형식 검증(예: PNU 19자리) |
| S2 | 지도/지오코딩 API 키 다수가 클라이언트 바이너리에 하드코딩, 키 순환으로 사용량 한도 회피 | High | 10, 20 | 모든 키는 서버 `.env`에만. `VITE_` 접두사 금지. 타일도 프록시 경유. 사용량 한도는 정상 범위에서 준수 |
| S3 | 전 구간 평문 HTTP (API·업데이트·파일 전송) | High | 10, 20, 30, 40 | 배포 시 HTTPS 전용 + HSTS. 업스트림 호출은 https만 |
| S4 | 인증 없는 서버 파일 쓰기, 추측 가능한 공유 URL | High | 40 | 서버 파일 저장 기능 없음. 사용자 데이터는 브라우저(IndexedDB)·파일 다운로드로만 |
| S5 | 라이선스/권한/건수 제한을 클라이언트에서만 판정 | Med | 20, 30, 40 | 제한이 필요하면 서버(프록시)에서 판정. 일괄 지오코딩 건수 제한은 서버에서 검증(현재 500) |
| S6 | 전송 데이터 보호를 가역 인코딩(Base64·치환 등)에 의존 | Med | 20, 40 | 자체 암호화 대신 TLS 사용. 클라이언트에 비밀값을 두지 않음 |
| S7 | 업데이트를 HTTP로 내려받아 실행(무결성 검증 미확인), 커스텀 URL 프로토콜로 외부에서 실행 가능 | Med | (정적 문자열 분석) | 웹 앱이라 설치형 업데이트 없음. 해당 없음 |
| S8 | 서버측 SQL 템플릿·설정이 클라이언트로 내려옴 | Med | 20 | 설정은 빌드 시 정적 config. 서버 로직을 클라이언트로 보내지 않음 |
| S9 | 바이너리에 담당자 개인정보 하드코딩 | Low | 40 | 개인정보를 코드·리소스에 넣지 않음 |
| S11 | 내부 DW 명세 문서(DW_데이터_명세_v1.0)에 외부 데이터 제공처 접속 계정·비밀번호, 파일 비밀번호, 내부 DB IP가 평문 기재 | High | 95 | 값은 어떤 노트·코드에도 옮기지 않음. 문서 배포 범위 확인 및 해당 계정 비밀번호 교체 권고. 접속정보는 비밀 관리 도구로 이전 |
| S12 | DW에 개인정보 성격 데이터(토지 소유자, 매물 판매자 연락처, 중개업자명, 사업자번호) 및 크롤링 원천 존재 | Med | 95 | 에이전트 응답·학습 데이터에서 제외, 크롤링 원천은 약관 검토 전 서비스 미사용 |
| S10 | 원본 서버 프록시성 엔드포인트(임의 url 파라미터) 존재 가능성 | Med | 10 | 우리 프록시는 고정 업스트림만 호출(SSRF 방지). 사용자 입력 URL로 fetch 금지 |

## 웹 버전 체크리스트
- [x] API 키 서버 전용 (`web/.env`, `.gitignore` 포함)
- [x] 프록시는 고정 업스트림 + 입력 검증 (`server/kakao.ts`, `server/vworld.ts`)
- [x] 업스트림 타임아웃 (8s)
- [ ] 프록시 rate limit (IP당) — 공개 배포 전 필수
- [ ] CSP / 보안 헤더 (배포 단계)
- [ ] 업로드 파일(xlsx/shp) 파싱은 브라우저에서, 크기·행 수 제한
- [ ] 키 로테이션: 대화에 노출된 키는 운영 전 재발급
- [ ] 서울 열린데이터광장 OpenAPI는 `http://openapi.seoul.go.kr:8088`(평문, 키가 URL 경로에 포함). 서버→서울시 구간만 사용하고 클라이언트에 노출 금지. HTTPS 지원 여부 재확인
- [x] 카카오 키는 플랫폼 도메인 제한 + 서버에서 KA 헤더(origin) 전송
