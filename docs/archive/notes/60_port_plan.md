## 단계
**P0 — 골격 (완료)**: Vite/React/TS/OL, Express 프록시, 키 분리·검증, 좌표계(GeoTrans 파라미터), 기본 뷰.

**P1 — 지도 셸 (원본 화면 구조)**
- 상단 메뉴(파일·검색·분석 도구·추가 및 심볼·보기), 광역시/시군구/동 선택(법정동코드)
- 왼쪽 패널: 사용자 분석 결과 Layer / 행정경계 / 지적도 및 국가공간정보 / 기본 POI
- 지도 툴바: 다각형·원(반경) 영역, 영역 열기·저장, 줌·이동·측정(km, km²), 뷰 히스토리
- 브이월드 WMS 오버레이(지적도 z≥15, 용도지역), 배경지도 색 필터
- 우클릭: 좌표 획득(경위도/TM/카텍/UTMK) + 필지 정보

**P2 — 사용자 데이터**
- 포인트 추가: xlsx/CSV/붙여넣기, X/Y 헤더 자동 인식, 좌표계 6종, 1만 행 제한
- SHP+DBF(CP949) 가져오기, 일괄 지오코딩(카카오, 행 번호 기준 결과 매칭)
- 레이어 모델(UserLayer/Style/Label/Project/Area) + IndexedDB 저장
- 심볼(마커 아이콘 241개 재사용 여부 확인), 라벨, 범례, 속성 테이블+요약
- 내보내기: KML, TXT(UTF-8 탭), PNG(배율 1–8)

**P3 — 분석 도구**
- 밀도(선형 커널, 10등급, 미터 거리 기본 + 원본 호환 옵션), 핫스팟 상위 5
- IDW 보간, 값 분류 4종 + 색 램프 13종, 버퍼(단일·목록), 영역 요약 통계

**P4 — 공공데이터 레이어**
- 업종별 분포(상가정보 → 밀도), 건물/실거래 속성 팝업, 필지 상세

**P5 — 선택 항목**: 고객사 모듈 중 일반화 가치 있는 것(Policy, SJ, ORBITECH, SB/TOZ), DT 이동시간 권역.
