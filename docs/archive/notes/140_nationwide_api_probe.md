# 140. 전국 확장 — API 수집 가능 범위 실측 (2026-10-30)

스크립트: `web/etl/nationwide-probe.ts` · 결과 DB: `data/nationwide_commerce.sqlite` (1.4GB, `api_feasibility` 테이블) · 원본: `data/lake/raw/` (gz, 113MB)
방법: 큰 소스는 `numOfRows=1`로 **총건수만 조회해 전량 호출 수를 계산**하고, 작은 소스만 실제 적재했다. 호스트별 호출 상한과 간격(공공데이터포털 0.9초/건, 직렬)을 걸어 한도를 보호했다.
사용 호출: 공공데이터포털 697 · R-ONE 600(상한 도달) · SGIS 55 · 브이월드 1 · 총 소요 약 20분.

## 2. 발견 사항 (설계에 반영할 것)

1. **지역 코드가 소스마다 다르다.**
   - 법정동코드·상가정보: 2026 신코드 사용, **12 = 전남광주통합특별시**.
   - SGIS: 통계청 코드(11, 21~26, 29, 31~39), 광주(24)·전남(36) 분리 유지.
   - 서울 상권분석: 행정동 8자리. 인허가: 개방자치단체코드 7자리 + 주소 문자열.
   - → **지역 코드 크로스워크 테이블**(법정동 10 ↔ 행정동 10/8 ↔ SGIS 8 ↔ 시군구 5 ↔ 자치단체 7, 유효기간 포함)이 P0 선행 작업이다. 통합 이전·이후 코드를 모두 가져야 시계열이 끊기지 않는다.
2. **공공데이터포털은 초당 제한이 있다.** 동시 4건에서 429(`LIMITED_NUMBER_OF_SERVICE_REQUESTS_PER_SECOND_EXCEEDS_ERROR`)가 발생했고, 0.9초 직렬로 697건을 오류 없이 처리했다. 일일 한도는 API별로 포털 마이페이지에서 확인해야 한다(운영계정 전환 신청 대상).
3. **상가정보 API에는 기준년월 필드가 없다.** 기준 시점은 `storeListByDate`가 응답하는 분기 기준일(20260630)로 기록한다.
4. **SGIS는 `low_search=1` 없이 상위 목록을 주지 않는다**(-100 "검색결과 없음").
5. R-ONE은 통계표 목록 738개 중 상업용 관련만 골라도 전 이력·전 지역이 50만 행을 넘는다. 서비스에 필요한 표(중대형·소규모 임대료·공실률·권리금)와 최근 N분기로 좁혀야 한다.

## 3. 수집 방식 결론

| 구분 | 소스 | 방식 |
|---|---|---|
| **API 전량 + 정기 증분** | 법정동코드, 상가정보(분기), 상권영역, 실거래(월), 공정위(연), SGIS(연), R-ONE(분기, 필터 후) | ETL 스케줄러 |
| **파일 전량 + 증분** | 인허가(업종별 CSV), 건축물대장(세움터), 연속지적·공시지가(국가공간정보포털), 국가표준격자, 지역 교통공사 승하차 | 다운로드 → 레이크 raw → 적재 |
| **API는 실시간 보조** | 카카오 지오코딩, 브이월드 필지 단건, 건축HUB 단건 | 에이전트 도구에서 필요 시 호출 |
| **서울 전용 API** | 서울 상권분석·생활인구·지하철 | 서울만 |
| **확보 불가 → 유료·추정** | 전국 매출·유동 | 유료 데이터 + 추정 모델 |
