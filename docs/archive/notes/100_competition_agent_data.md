# 상권 경쟁력 분석 AI Agent — 필요 데이터와 API 확보 가능성 (v0.2)

작성일 2026-10-29 · 범위: 1차 서울, 이후 전국 · 근거: 레퍼런스 화면(XRayMap, 소상공인365, 오픈업), 70/80/90/95/110 노트, API 실호출 결과

**v0.2 변경 사항**
- 추가 신청한 API의 실호출 결과를 반영했다. 공정위 가맹정보 2종과 아파트 실거래가가 동작한다.
- 일반음식점 인허가는 파일로 제공된다. 공정위 페어데이터는 활용신청이 막혀 있고, 네이버는 보류다.
- 모든 표에 **전국 확보 경로** 열을 추가하고, 전국 확대 요약(§5)을 넣었다.

## 1. 목표

사용자가 **위치(주소·좌표·상권·그린 영역) + 업종**을 주면 에이전트가 아래 질문에 근거와 함께 답한다.

| # | 에이전트가 답할 질문 | 레퍼런스 대응 |
|---|---|---|
| Q1 | 여기서 **경쟁점**은 누구고 몇 개인가? 최근 생기고 사라진 곳은? | 오픈업 상권 매장·신규매장 / 소상공인365 업소 |
| Q2 | 이 업종의 **수요**는 충분한가? 언제, 누가 오는가? | 소상공인365 유동·직장·주거인구 / XRayMap 측정지점 시간대 |
| Q3 | 이 상권 동업종의 **매출 수준**과 내 위치의 기대 매출은? | 오픈업 건물별 추정매출 / 소상공인365 매출 |
| Q4 | **경쟁 강도·포화도**는? 수요 대비 점포가 많은가? | XRayMap 업종별 밀도·핫스팟 |
| Q5 | **비용**(임대료·권리금·창업비) 대비 수익성은? | 오픈업 창업계산 |
| Q6 | 이 상권은 **뜨는가, 지는가**? (성장·신생·역주행·MZ·배달) | 소상공인365 트렌드분석 테마상권 |
| Q7 | **관심도·평판**은? (SNS 언급, 연관어) | 소상공인365 SNS 분석 |
| Q8 | 종합하면 **경쟁력 점수**와 리스크는? | 소상공인365 경영진단, 기존 DW `ibk_score` |

레퍼런스보다 정밀해지는 지점:
- 분석 단위를 **행정동·상권 → 건물·필지·반경 n m·사용자 다각형**까지 내린다(오픈업 수준).
- 상권 경계를 행정 단위가 아니라 **실제 점포 분포 기반(밀도·핫스팟)**으로 자동 생성한다(XRayMap 방식 복원).
- 고객 프로필(성·연령·시간대)의 **수요 측(유동)과 매출 측(카드)을 맞대어** 비교한다. 레퍼런스는 둘을 따로 보여준다.

### Q8 종합 점수
- 기존 DW `ibk_score`(성장성·안정성·구매력·수익성·집객력 등 35개)와 `store_closure`(휴폐업 확률)의 **정의를 재사용**한다. 입력만 공개 API와 최신 데이터로 바꿔 다시 계산한다.
- 소상공인365 경영진단 지표(내점률·인구집중도·상권점유율·성장성·안정성·생존가능성)는 정의가 공개돼 있어 함께 산출한다.
- 서울 밖은 매출·유동 항목이 유료 데이터 또는 추정 모델(§5)에 의존한다. 그래서 점수와 함께 **신뢰등급**(직접 관측 / 보정 / 추정)을 표시한다.

| `score_report` | 영역, 업종 | 종합 점수, 신뢰등급, 리스크, 근거 표 | 위 전체 |

모든 출력에 **기준 시점·출처·추정 여부·신뢰등급**을 붙인다. 예: "서울 추정매출은 신한카드 기반 추정치, 2026Q2".
