# 80. 상권분석 AI Agent — 데이터 소스 카탈로그 (지표 → 소스 → 수집 가능성)

작성: 2026-10-29 · 범위: 1차 서울, 이후 전국(유료·ETL 허용) · 근거: 공개 웹페이지(WebSearch/WebFetch). 키가 필요한 API는 호출하지 않았다.
표기: **[검증됨]** = 우리 키로 이미 호출 확인(60_port_plan.md), **(확인 필요)** = 공개 페이지에서 직접 확인하지 못했거나 2차 자료만 있음.
라이선스 약어: KOGL1 = 공공누리 1유형(출처표시, 상업적 이용·변경 가능). "제한 없음" = data.go.kr의 "이용허락범위 제한 없음".
ETL 열: ★ = 대량 파일(bulk)로 받아 적재하는 편이 맞음, ◇ = API 증분 호출로 충분/필수.

## 0. 핵심 사실 요약 (2026년 변경사항 포함)

1. **서울 생활인구 체계 전환**: 집계구 단위 생활인구(OA-14979 등)와 행정동 단위 생활인구(OA-14991)는 "국가표준격자(250m) 단위로의 전환으로 2026-07-31 이후 생산 종료". 2017-01-01~2026-07-31 구간은 아카이브로 남는다. 출처: https://data.seoul.go.kr/dataVisual/seoul/seoulLivingArchive.do , https://data.seoul.go.kr/dataList/OA-14991/S/1/datasetView.do
   - 신규 250m 계열 공개 데이터셋(2026-07-29 공개)은 **250m 격자를 자치구 단위로 집계한 것**(OA-23019/23020/23021, 일별집계 OA-23022·OA-23060)이며, 페이지에 격자 ID 컬럼 언급이 없다. 즉 **격자 원자료의 공개 여부는 확인 필요**. Sheet/API는 당해 1/1~D-4, 연도 파일은 2023~2025. 출처: https://data.seoul.go.kr/dataList/OA-23019/S/1/datasetView.do
   - 행정동 단위 250m 기반 데이터셋은 관련 목록에 없음(확인 필요 — 추가 공개 예정인지 공지 확인 필요).
2. **서울 상권분석서비스 공간단위 변경**: 2024년부터 공간 단위가 "표준단위구역"으로 바뀌었고, 2026-07-03부터 추정매출은 **2021년 이후 자료만** 제공(카드사가 표준단위구역 매출을 2021년부터 공급). 출처: https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do
   - 소비(상권) 데이터는 "행정동보다 작은 상권 크기 제공 어려워 더 이상 갱신되지 않음", '월평균소득금액' 컬럼은 2026-05-13 삭제, '소득구간코드'는 2026-06-25 삭제 예정. 출처: https://data.seoul.go.kr/dataList/OA-21278/S/1/datasetView.do (검색 요약 기준, 본문 재확인 필요)
3. **LOCALDATA 인허가 데이터 이관**: 2026-01-25 행안부가 인허가 195종 + 생활편의 14종 = 209종을 공공데이터포털(data.go.kr)에서 통합 공개, 전부 API 제공. localdata.go.kr 폐쇄 여부는 기사에 없음(확인 필요). 출처: https://www.khan.co.kr/article/202601251400011/
4. **공공누리 1유형 ≠ AI 학습 명시 허용**: 공공누리에는 별도의 "AI 유형"이 있으며, AI 유형 표시 자료에 한해 AI 학습 목적 출처 생략 특례가 있다. 1유형만 붙은 자료의 AI 학습 이용은 "출처표시 + 상업적 이용·변경 가능" 조건 내에서 해석해야 함 → 법률 검토 필요. 출처: https://www.copyright.or.kr/gov/nuri/guide/index.do , https://www.mods.go.kr/menu.es?mid=a10706000000 , https://www.korea.kr/briefing/pressReleaseView.do?newsId=156786078

## 9. 오픈 이슈 / 리스크

1. **AI 학습 라이선스**: 대부분 KOGL1 또는 "이용허락범위 제한 없음". 공공누리 AI 유형은 별도이며 1유형에 AI 학습이 명시되진 않음(https://www.copyright.or.kr/gov/nuri/guide/index.do). 통신·카드 유료 데이터는 계약상 "연구·신규서비스 개발 외 용도 금지"(KT 2021 사례, https://www.fnnews.com/news/202103281045140503) 등 재가공·재배포·모델학습 조항을 계약 시 명시해야 함. 카카오 로컬 결과의 DB 적재·학습 이용은 약관 확인 필요.
2. **SGIS 약관**: 영리 이용 금지하지 않는다는 문구는 통계 오픈API 일반 안내에서만 확인(https://www.index.go.kr/unity/openApi/openApiIntro.do) — SGIS 자료제공 파일의 상업 이용 조건은 확인 필요.
3. **시계열 단절**:
   - 서울 생활인구 행정동/집계구 → 250m 격자 전환(2026-07-31). 공개 신규 데이터가 자치구 집계뿐이면 **행정동 단위 2026-08 이후 공백** 가능. 격자 원자료 공개·요청 경로 확인 필요.
   - 서울 추정매출 2021 이전 삭제, 표준단위구역 전환(2024~) → 과거 다운로드본과 상권 경계·코드가 불일치할 수 있음. **지금 시점의 전량을 스냅샷 보관**할 것.
   - 상가정보 업종분류 개편(표준산업분류 기반 10/75/247) → 과거 분기와 업종 매핑 필요.
   - 인허가 데이터 LOCALDATA→data.go.kr 이관(2026-01) → 컬럼/키 변경 여부 확인 필요.
4. **공간단위 불일치**: 서울 상권(보행권역/표준단위구역) ≠ 소상공인 상권영역 ≠ R-ONE 상권 ≠ 행정동 ≠ 집계구 ≠ 250m 격자. 면적·인구·점포 가중 크로스워크 테이블을 1급 산출물로 관리해야 함. 행정동은 분·합동으로 자주 변경 → 버전 관리(기준일) 필수.
5. **추정치의 추정치**: 추정매출은 단일 카드사(신한) × 보정비율 기반(https://golmok.seoul.go.kr/images/seoul_info.pdf). 모델 학습 타깃으로 쓰면 원 추정 모형을 학습하게 됨 → 타깃 신뢰도 표기 필요. 생활인구 3명 이하 마스킹([*]).
6. **신선도**: 상권분석 분기(약 1분기 지연), 상가정보 분기, 생활인구 일(D-4~), 지하철 월(익월 5일), R-ONE 분기, 실거래 월(신고기한 30일 지연). 에이전트 답변에 "기준 시점" 메타데이터를 항상 노출.
7. **전국 확장의 핵심 공백**: 유동인구·매출·소비·소득은 전국 무료 대체재가 없음 → 통신사 1곳 + 카드사 1곳 유료 계약이 전제. 가격은 공개되어 있지 않아 견적 필요(금융데이터거래소 실거래 미미, 맞춤 계약 위주: https://www.heraldk.com/article/2025110618162638392).
8. **API 쿼터**: 상가정보 API 개발계정 10,000건(https://www.data.go.kr/data/15012005/openapi.do) → 전량은 파일로, API는 검증·실시간 조회에만.
9. **미확인 목록(다음 조사 대상)**: 서울 250m 격자 원자료, 경기 생활인구, 전국 교통카드 승하차, 소상공인365 Open API, KDX/데이터댐 상품 가격, ECOS 지역 카드승인액, 국가표준격자 ID 규격, 건물관리번호 vs GIS건물통합 키, 서울 상권코드 자릿수·표준단위구역 정의, 추정매출 CSV 컬럼(매출건수 포함 여부).
