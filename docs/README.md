# 상권 경쟁력 분석 AI Agent — 문서

**"이 자리에서 이 업종을 하면 경쟁력이 있는가"**에 근거와 함께 답하는 AI Agent를 만드는 프로젝트다. 서울에서 파일럿으로 검증하고 전국으로 넓힌다.

## 지금 상태 (2026-10-30)

| 구분 | 상태 |
|---|---|
| 단계 | 조사·실측 완료, 파일럿(P0) 착수 전 |
| DB | `data/commerce.sqlite` 1.6GB — 서울 상권·인구·지하철, 서울 점포 55만, 전국 인허가 231만, 전국 SGIS·상권영역·공정위 |
| 대기 | 실거래 (공공데이터포털 운영계정 전환 후), 인허가 업종·주민등록 인구 API 활용신청 ([TODO](TODO.md)) |
| 전국 | 점포 275만(2026-09)·전국 상권영역·R-ONE 임대료·건축물대장 연결 완료. 서울 밖에 없는 것: 유동인구, 매출 |
| 컨셉 | 로드뷰 이미지 + 위치 → 출점·출자 적합도 점수 (참고용). Agent API로 제공 ([08](08_API_명세.md)) |
| 다음 작업 | Agent API v0와 심사 화면 v0 완료 (`npm run dev` → `localhost:8000`, Swagger는 `/api/docs`). 카카오 JS 키·Claude 키 넣고 로드뷰·판독 검증 |
| 결정 | 서빙 PostgreSQL(D2)·레이크 S3(D3) 확정. 남은 것: 구매 데이터(D1), 파일럿 사용자(D4), 대화 로그 정책(D5) |

## 저장소 구성

```
docs/        문서 (이 폴더)
web/         지도 웹앱 + API 서버(Swagger: server/openapi.yaml) + ETL (web/etl)
ml/          점수·생존·매출 모델 v0 (Python, ml/.venv)
data/        DB와 원본 (commerce.sqlite, lake/raw, raw/일반음식점 CSV)
re/          XRayMap 디컴파일 산출물 (내부 참고용)
```
