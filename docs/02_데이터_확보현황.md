# 02. 데이터 확보 현황

> **요약**
> - 서울은 공개 데이터만으로 경쟁점·수요·매출·비용·트렌드까지 상권 단위로 답할 수 있다.
> - 전국은 경쟁점·개폐업·인구·비용·프랜차이즈까지 공개 데이터로 된다. **매출은 서울 밖에서 공개 데이터가 없다** → 구매 데이터 + 추정 모델.
> - 유동·생활인구 원자료를 공개하는 광역은 **서울·경기·부산**뿐이다 (경기 파일 2유형, 부산 API 제한 없음). 나머지는 경기로 학습한 추정값을 쓴다. 전국 실측은 통신 3사 상품 **(구매필요)** — 4-1장.
> - 기존 DW에 구매 데이터(카드 매출·통신 유동인구·KCB)가 있지만 2024년 중반에 멈췄다.
> - 검색 관심도(네이버)는 API 이관 중이라 보류.

## 4-1. 서울 밖 유동·생활인구 후보 (2026-11-02 조사)

정의를 먼저 구분한다. **생활인구 = 그 시간에 그 동에 *있는* 사람 수** (새벽 ≈ 주민 수), **유동인구 = 그 시간에 *움직이는* 사람 수** (새벽 ≪ 주민 수). 둘은 하나의 정답으로 섞어 학습하지 않는다 (경기 실측으로 확인: 새벽/주민 서울 0.98 vs 경기 0.075).

### 광역단체 자체 포털 (무료)

서울 열린데이터광장·경기데이터드림처럼 **통신 원자료를 자체 포털에서 계속 내려받게 하는 곳은 서울·경기뿐**이다. 부산은 자체 포털이 있지만 원자료는 공공데이터포털에 같은 것이 올라가 있다. 나머지는 포털이 있어도 통신 유동인구 원자료가 없거나 시각화만 있다.

| 광역 | 자체 포털 | 통신 유동·생활인구 | 우리 판단 |
|---|---|---|---|
| 서울 | 열린데이터광장 | ✅ 생활인구(KT) · 상권 유동인구. 2026-08부터 250m 격자 전환 | 사용 중 |
| 경기 | 경기데이터드림 | ✅ 유동인구 행정동(KT) 파일, 공공누리 2유형 | 사용 중 (내부 심사 한정) |

"이용허락범위 제한 없음" | 활용신청 1건이면 됨 → 진행 |

| 대전·울산 | 별도 포털 확인 안 됨 | 구 단위 파일만 공공데이터포털에 산발 (대전 서구·중구 등) | 쓰지 않음 |

- 인구가 많지 않은 지역마다 구·군 파일을 모으는 것은 효과에 비해 비용이 크다. 서울·경기·부산 외 지역은 **추정 모델 + 통신사 상품(구매필요)** 으로 간다.

### 권장 순서
1. **부산 API 활용신청 (사용자, 무료)**: 경기 다음으로 큰 실측 지역이다. 정의가 *생활인구*라 서울과 같은 쪽이므로, "서울+부산 생활인구 모델"을 별도로 만들어 경기 *유동인구* 모델과 비교할 수 있다. 이용조건 "제한 없음"이라 외부 제공도 가능성이 높다 (원문 확인 후 10장에 ✅).
2. **SKT 지오비전 퍼즐 무료 요금제로 API 시험**: 단위·필드·정의를 확인하고, 견적 요청 근거를 만든다.
3. **KT PLIP 견적 (구매필요)**: 전국 행정동 × 시간 유동인구. 경기 2유형 문제(L-1~L-3)도 같은 창구에서 함께 정리할 수 있다.

### SNS식 상권 이름 (용리단길·망리단길 등)
- 사람들이 부르는 상권 이름은 정식 행정·상권 이름과 다르다 (삼각지 일대 = 용리단길).
- **이름 → 위치는 대부분 카카오로 해결된다.** 카카오가 "테마거리" 분류로 등록해 둠: 용리단길, 망리단길, 송리단길, 샤로수길 모두 상권 검색에서 바로 나옴 (2026-11-03 확인). 서울 상권분석에도 망리단길·샤로수길·송리단길이 골목상권 이름으로 있음.
- 빠지는 경우: 카카오에 다른 이름으로만 있는 곳 (객리단길 → 카카오 "객사길").
- 대응
  1. **상권 별칭 사전** (바로 가능, 무료): 카카오 테마거리를 전국으로 모아 기본으로 쓰고, 빠진 별칭은 직접 추가 (`area_alias`: 별칭 → 정식 이름·위치). 상권 검색이 별칭도 받게 함.
  2. **화제성**: 별칭 사전의 이름으로 네이버 데이터랩 검색량 추이를 받아 상권 리포트에 표시 (D10).
